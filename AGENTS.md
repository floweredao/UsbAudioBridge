# AGENTS.md

## README rules

- `README.md` (English) and `README-ko.md` (Korean) keep the same structure: name, one-line pitch, 3-6 strengths, screenshots, Install (numbered, from the release files), First use, FAQ, then How it works, Project layout, Build from source.
- Screenshots match the README's language: `README.md` uses `docs/tablet-en-*.png`, `README-ko.md` uses `docs/tablet-ko-*.png`. Light mode comes first, dark mode second, one image per line.
- Describe what this app does and why it is good on its own terms. Do not name other apps or products (other audio, virtual-device, or remote-desktop apps) and do not write comparisons such as "instead of X", "like X", or "X is no longer needed", unless the owner asks for it.
- Only state numbers that were measured, and keep them consistent with the latency table.
- Retake screenshots with the tablet's own language and theme, crop the status bar, check for personal information, and restore the tablet's language and theme afterwards. Never play sound on the tablet while taking them.
